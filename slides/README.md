# Marpスライドの編集方法

1. VS Codeで編集するスライドのMarkdownファイルを開く
2. 推奨拡張機能として表示される `Marp for VS Code` をインストールする
3. `Ctrl + Shift + V` でプレビューを開く
4. コマンドパレットから `Marp: Export Slide Deck...` を実行する

レイアウトは `themes/graduation-research.css` で調整できます。
このワークスペースではMarpのカスタムテーマとHTML表示を設定済みです。
